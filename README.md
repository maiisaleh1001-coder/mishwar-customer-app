# مشوار · تطبيق العميل

تصميم تطبيق «مشوار» للعميل: توصيل أفراد، وتوصيل طرود، ومرافق شخصي بالساعة، ومعاملات حكومية، في السعودية.

## المحتوى

| المسار | فيه إيه |
|---|---|
| `design-canvas/project/` | شاشات التصميم (`*.dc.html`) وترتيبها على الـ Canvas (`canvas.json`) |
| `provider-canvas/project/` | شاشات تطبيق مقدم الخدمة (P-xx، 112 شاشة) على Canvas منفصل |
| `ui/index.html` | بروتوتايب تطبيق العميل (104 شاشة)، يفتح في المتصفح مباشرة |
| `ui/provider.html` | بروتوتايب تطبيق مقدم الخدمة (112 شاشة) |
| `index.html` | صفحة عرض واحدة تبدّل بين البروتوتايبين |
| `ui/UI-GUIDELINES.md` | الألوان والخطوط والمسافات والـ Components وقواعد الكتابة (لهجة سعودية بيضاء) |
| `ui/a11y-report.md` | مراجعة Accessibility على WCAG 2.2 AA |
| `ui/assets/` | الأيقونات الـ 3D، والخرائط، ورمز الريال الرسمي |
| `ui/map-source/` | سكريبت رسم الخرائط وبيانات الشوارع من OpenStreetMap |
| `customer-app-analysis.md` | تحليل المتطلبات وسجل القرارات (D1 → D30) والأسئلة المفتوحة |
| `provider-app-analysis.md` | تحليل تطبيق مقدم الخدمة: الأدوار والقواعد والشاشات والفجوات والأسئلة (P-D1 → P-D31) |

## تشغيل البروتوتايب

أونلاين: **https://maiisaleh1001-coder.github.io/mishwar-customer-app/**

بروتوتايب مقدم الخدمة: **https://maiisaleh1001-coder.github.io/mishwar-customer-app/ui/provider.html**
فيه فهرس بكل الشاشات حسب الـ Flow، و18 مسار كامل للمراجعة، و«أحداث من النظام» للحالات اللي تصير من العميل أو الإدارة (عرض جديد، اعتماد الحساب، العميل لغى...). وزرار «أظهر الأزرار وين توديك» يبيّن كل زرار يودّي لشاشة أو للعرض بس.
(بيتولّد من `provider-canvas` بالسكريبت `ui/build-provider-screens.ps1`، فبعد أي تعديل في الـ Canvas شغّله تاني.)

أو افتح `ui/index.html` في المتصفح. ولأي شاشة معيّنة ضيف رقمها في آخر الرابط، مثلاً `index.html#C-10e`.
